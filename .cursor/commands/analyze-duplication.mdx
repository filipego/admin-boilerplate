# 🔁 Analyze and Reduce Duplication

## Goal

Scan the specified directory or file group to find duplicated logic or UI patterns that could be extracted into shared components or helpers.

## Instructions

- Focus on identifying similar components, functions, or patterns (e.g., repeated fetch logic, form structures, etc.)
- Highlight areas where small wrappers or utility functions could clean things up.
- If you find repeated JSX, recommend a shared UI component.

## Output

1. List each duplication cluster with file names and matching lines.
2. Suggest or apply a fix that introduces a reusable element.

## Notes

Prioritize readability and alignment with existing architecture (e.g., MCP, wrapper system).
