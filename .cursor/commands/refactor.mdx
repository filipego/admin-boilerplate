# 🧼 Refactor for Clarity and Reuse

## Goal

Clean up the current implementation by removing duplication, improving naming, and moving logic into reusable components or helpers. Do not change functionality or layout.

## Instructions

- Keep all existing functionality and styling.
- Use early returns and break large files into smaller units if needed.
- Move duplicated logic to helper functions or shared components.
- Use the existing design tokens (e.g., `--primary`, `--muted`, etc.).
- Use wrapper components instead of direct ShadCN usage.
- If you touch any CSS or tailwind, make sure it's using existing tokens and variables.

## Output

List which files/components you modified and briefly describe what changed in each.

## Notes

This command is meant to preserve layout/UX while improving developer experience and maintainability.
