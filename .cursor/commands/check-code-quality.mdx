# 🕵️ Code Quality Audit

## Goal

Scan the listed files or directory for code quality issues and offer suggestions or edits to improve readability, performance, or maintainability.

## Instructions

- Flag any duplicated logic, magic values, hardcoded strings/colors, or inconsistent naming.
- Do not change functionality unless you find a bug.
- Follow project conventions: early returns, use of wrappers, and design tokens.
- Add comments where context is needed.

## Output

1. List each issue with file/line number and a short explanation.
2. Suggest or apply a clean solution (explain your fix if it's non-obvious).

## Notes

You may suggest a larger refactor, but only do it if it clearly reduces tech debt.
