# ✅ Add Unit Tests

## Goal

Write tests for the given feature or component to ensure behavior is stable and correct.

## Instructions

- Use Vitest or Jest (match the project setup).
- Include one happy path test and at least one edge case.
- Mock Supabase, Zustand, or other services as needed.
- Keep tests colocated if the project follows that convention.

## Output

Provide:

- New test file(s)
- A summary of what each test covers
- Any assumptions or areas where test coverage is limited
